# TAGTOG Portal v2 — sumber desain

Desain native yang dapat diedit di **FigCraft 0.8.0**.

- `tagtog-portal.figcraft` — file utama dengan artboard desktop 1440 × 960 dan mobile 390 × 1530.
- `desktop-design.png` — render artboard desktop.
- `mobile-design.png` — render artboard mobile.
- `design-tokens.json` — palet, tipografi, radius, dan ukuran tata letak.
- `build-design.json` — instruksi CLI untuk merekonstruksi layer desain.

Semua elemen berupa frame, teks, bentuk, dan vektor native yang dapat diedit; tidak memakai tangkapan layar atau aset gambar eksternal.

Arah desain: sidebar gelap, welcome tipografis tanpa banner foto, tiga kartu EMS/PMS/CRM dengan visual berwarna dan tombol panah melingkar. Cakupannya portal pemilih aplikasi. Tidak ada checklist, aktivitas, jadwal, grafik, atau quick links.

Tipografi menggunakan Bahnschrift untuk headline dan Segoe UI untuk teks. Angka waktu/profil di artboard adalah contoh visual.
